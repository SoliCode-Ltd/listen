Listen Reader — Chrome Extension
Created and crafted by SoliCode Ltd. (https://solicode.co.uk)

All voice synthesis is powered by Listen's proprietary speech engine.
Audio is generated server-side through the Listen API.

Installation:
1) Open chrome://extensions
2) Enable Developer mode
3) Click Load unpacked
4) Select this folder
5) Open extension popup and configure API key
6) Select text on any page and use context menu: Listen Selected Text
