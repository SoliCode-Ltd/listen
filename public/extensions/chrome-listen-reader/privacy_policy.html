Listen Reader — Privacy Policy

Last updated: October 2026

What data we collect

The Listen Reader extension processes text you explicitly select on web pages and sends it to the Listen API for voice synthesis. We collect:

  • Selected text: Only the text you actively select and choose to convert to speech.
  • API key: Stored locally in Chrome storage and sent with each API request for authentication.
  • Extension settings: Your language, voice, and playback preferences — stored locally in Chrome storage.

What we do NOT collect

  • We do not track your browsing history or monitor page content.
  • We do not inject ads or analytics trackers.
  • We do not collect personal information beyond what is in your Listen account.
  • We do not sell or share your data with third parties.

How data is processed

Selected text is sent to the Listen API server over HTTPS for voice synthesis. The generated audio is streamed back to the extension. Text is not stored permanently on the server beyond what is needed for your account's usage history.

Permissions explained

  • storage: Save your settings and API key locally.
  • activeTab: Read selected text from the current tab when you trigger the extension.
  • scripting: Inject the audio player panel into web pages for playback.
  • contextMenus: Add "Listen to the selected text" to the right-click menu.
  • tabs: Identify the active tab to deliver audio playback.
  • alarms: Schedule periodic config refresh checks.
  • host_permissions (all URLs): Required to read selected text and inject the audio player on any website you visit.
